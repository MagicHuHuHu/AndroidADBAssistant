# ADB 助手

运行在 Android 设备 A 上，通过无线 ADB 管理 Android 设备 B。Kotlin + Jetpack Compose 原生界面，最低支持 Android 11。

## 功能

- 设备：六位码无线配对、IP 直连、保存最近连接地址、截图预览后保存、返回键、主页键、设备信息、打开设置、重启。
- 应用：用户/系统应用列表、包名搜索、versionCode 和 versionName、安装 APK、启动、强制停止、清除数据、卸载、导出基础 APK。
- 文件：目录浏览、新建文件夹、多选上传/下载、递归下载文件夹、上传同名冲突确认、系统下载目录选择、进度与平均速度、取消、失败重试。
- 终端：在深色区域的路径提示符处直接输入，按 Enter 执行；保留当前工作目录，支持 `cd`、相对路径、中文和空格目录，切换失败保留原目录，重新连接时重置。连续保留命令和输出，支持选择复制、常用命令、会话历史、输出清空、停止与 30 秒超时。当前仍为单次 shell 执行，仅保留工作目录，不保留环境变量，不支持交互式程序；停止或断流时不采用未完整返回的目录。

应用管理以真实包名、versionCode 和 versionName 展示应用；尚未提取应用名称和图标。拆分应用导出的基础 APK 不能替代完整的 split APK 集合。文件夹递归上传、后台保活和断点续传尚未实现，传输时请保持应用在前台。

## 连接步骤

1. A 与 B 接入彼此可访问的网络。在 B 开启开发者选项和无线调试。
2. B 打开“使用配对码配对设备”，把 IP、配对端口、六位配对码输入 A，点击“配对设备”。
3. 回到 B 的无线调试主页，把主页显示的连接端口输入 A，点击“连接设备”。连接端口与配对端口不同，关闭无线调试后可能变化。
4. 已开启传统 TCP/IP ADB 的设备可通过“IP 直连”连接，并在 B 上接受调试授权。

不需要 Root；受设备 B 的 ADB shell 权限与厂商限制约束，不能读取其他应用的私有数据。无线配对证书和私钥保存在 A 的应用私有、禁止备份目录内。

## 文件传输

在“文件”中浏览的是 B 的目录。上传通过系统文件选择器选取 A 的文件；下载前先选择 A 的保存目录。下载同名文件由系统文档提供器创建独立副本。上传先写随机临时文件，再移动到目标文件；覆盖需要确认。取消或失败会尝试清理临时文件，设备断线时清理可能失败。

文件夹左侧的复选框用于选择下载，点击文件夹名称仍然进入目录。下载先扫描目录，再保留层级及空目录逐项保存；任务显示整体字节进度、当前文件、完成数量和失败项。同名目录创建带序号的副本。不可读取的文件或目录记录为失败，其他文件继续下载；符号链接跳过，避免循环遍历。取消时保留已完成内容，并尝试删除未完成的当前文件。文件夹重试会重新下载到新的副本目录。

传输任务显示方向、已传输大小和平均速度。应用进程退出后任务记录不保留。失败的下载重试会创建新的目标文件；上传重试需要原始 URI 授权仍然有效。截图点击后先预览，选择“不保存”直接关闭，点击“保存截图”才选择位置，保存原始 PNG。

## 构建

安装 JDK 17 或兼容版本、Android SDK 36，在 `local.properties` 中设置 `sdk.dir`。首次构建需要从 Google Maven、Maven Central 和 JitPack 下载依赖。

```powershell
.\gradlew.bat assembleDebug testDebugUnitTest lintDebug
```

APK：`app/build/outputs/apk/debug/app-debug.apk`。

ADB 通信基于 [libadb-android 3.1.1](https://github.com/MuntashirAkon/libadb-android)，配对与 TLS 由该库实现；证书使用 Bouncy Castle 生成。上游库采用 Apache-2.0 或 GPL-3.0-or-later 双许可，使用时按其许可保留声明。

## 验证范围

已在 Android 13 的 X1 Pro 上安装并检查四个页面。7 项单元测试覆盖文件协议、中文文件名、分块传输、二进制完整性、异常断流和危险文件名。真机集成测试通过临时 USB 中继访问实际设备的 ADB 服务，覆盖 2 MB 文件往返、中文命令、versionName、文件 URI 上传下载、截图预览和保存、返回与主页快捷键、嵌套目录、空目录、零字节文件、同名副本、取消、无权限目录及符号链接处理。

这些测试验证了实际设备上的命令和文件操作，但不能代替两台设备之间的无线配对、TLS 和局域网直连测试；后者仍需使用设备 B 手动验收。暂停续传、文件夹递归上传、后台保活暂未实现。

`tools/testing/` 和 `app/src/androidTest/` 为测试专用文件。临时中继仅监听电脑回环地址；测试结束后应停止脚本并移除 `adb reverse tcp:18777` 映射，不要用于正式连接。
